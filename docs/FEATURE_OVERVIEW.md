# Career Copilot - Feature Overview

Career Copilot integrates every stage of a tech professional's hiring journey into an integrated loop:

---

## 📄 1. Resume Analyzer & ATS Optimizer
- **PDF Extraction**: In-memory parsing of uploaded resumes using `pdf-parse`.
- **ATS Keyword Matching**: Tokenizes and compares resume content against the requirements of 20 target tech roles.
- **Section Extraction**: Discovers Education, Work History, Core Skills, and Projects.
- **Actionable Optimization**: Detects missing role-specific keywords, gives quantifiable impact suggestions, and generates an ATS compatibility score.

---

## 📋 2. Job Application Tracker (Kanban)
- **Visual Workflow**: Drag-or-click card transitions between 5 stages:
  1. *Wishlist*
  2. *Applied*
  3. *Interviewing*
  4. *Offer*
  5. *Rejected*
- **Metrics & KPIs**: Response rates, active pipeline counts, upcoming interview dates, and offer conversion stats.
- **Interview Notes**: Log recruiter feedback, technical rounds, salary ranges, and contacts.

---

## 🎯 3. Skill Gap Analysis
- **Role Selection**: 20 target tech roles (Frontend, Backend, Fullstack, DevOps, Data Engineer, Machine Learning, Mobile iOS/Android, Cloud Architect, Cybersecurity, etc.).
- **Proficiency Audits**: Self-assess competencies (Beginner, Intermediate, Advanced, Expert).
- **Gap Highlighting**: Highlights high-priority missing skills required for candidate shortlisting.
- **Curated Learning**: Provides direct resources (documentation, interactive courses, GitHub repos) for missing competencies.

---

## 📅 4. Adaptive Study Planner
- **Algorithmic Schedule**: Calculates weekly study allocations based on candidate skill gaps and available weekly study hours.
- **Milestone Tracking**: Daily actionable tasks with status checkmarks and dynamic progress bars.
- **Schedule Recalibration**: Automatically recalibrates milestones based on practice pacing.

---

## 💻 5. Coding Practice Tracker
- **Multi-Platform Support**: Track problems solved on LeetCode, HackerRank, Codeforces, NeetCode, etc.
- **Taxonomy**: Filter and organize by Data Structures & Algorithms topic (Arrays, Dynamic Programming, Graphs, Trees, Strings, System Design).
- **Weakness Identification**: Surfaces topic areas with lowest solve ratios or highest review flags.

---

## 🎙️ 6. Mock Interview Simulator
- **Multi-Track Sessions**: Choose from Technical Coding, System Design, or Behavioral (STAR format).
- **Curated Question Bank**: 100+ categorized questions with rubrics and expected concepts.
- **Rubric Evaluation**: Comprehensive breakdown on clarity, depth, technical accuracy, and structure.

---

## 📈 7. Unified Readiness Score
Aggregates candidate performance into an intuitive 0-100% readiness indicator:
- **Resume Score (25%)**: ATS compatibility and completeness.
- **Skill Alignment (25%)**: Percentage of target role essential skills validated.
- **Coding Practice (25%)**: Problem count and topic coverage threshold.
- **Interview Readiness (25%)**: Average score across completed mock sessions.
